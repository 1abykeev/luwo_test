## AI

| Technology | What it does here |
|---|---|
| **Claude Haiku 5.5** (Anthropic API) | The model behind the agent, chosen as the cheapest one that handles tool use well |
| **Tool use** | Claude calls our 19 tools instead of touching data itself |
| **Prompt caching** | Reuses the system prompt and tool list between calls: cheaper and faster |

## Database and infrastructure

| Technology | Version | What it does here |
|---|---|---|
| **PostgreSQL** | 16 | The real database: students, classes, history, chats, analytics |
| **Docker** and **Docker Compose** | - | Runs Postgres (and, optionally, Prometheus and Grafana) |
| **Prometheus** | 3.3 | Collects the metrics from `/metrics` and stores their history |
| **Grafana** | 11.6 | Draws the dashboard from Prometheus's data |

How the monitoring pieces fit together:

```
Backend /metrics  ->  Prometheus  ->  Grafana
(produces numbers)    (collects and    (draws charts
                       stores them      from the stored
                       every 5 s)       numbers)
```

Only `/metrics` is part of the application. Prometheus and Grafana are separate programs started with
`docker compose --profile observability up -d`; the app works without them.
